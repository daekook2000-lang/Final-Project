
# Chef's Cuisine - Frontend Maintenance

## 프로젝트 개요

Chef's Cuisine의 프론트엔드는 React를 기반으로 구현되었으며,
레시피 탐색과 회원정보 관리 기능을 제공합니다.

본 문서는 프론트엔드의 주요 기능과 향후 점검 항목을 정리한 문서입니다.

## 기술 스택

- React
- JavaScript
- HTML / CSS
- Vite
- React Router
- Axios

## 주요 기능

### 회원 관리
- 로그인 및 회원가입 화면
- 회원정보 조회 및 수정
- 프로필 이미지 업로드 및 미리보기
- 마이페이지

### 레시피 탐색
- 레시피 목록 조회
- 레시피 검색 및 정렬
- 난이도, 조리시간, 태그, 재료별 필터
- 레시피 상세 정보 조회

### 스크랩
- 레시피 스크랩 상태 표시
- 마이페이지 스크랩 목록 조회

## 향후 점검 및 개선 항목

### 회원 관리
- [ ] 로그인 상태에 따른 화면 처리 확인
- [ ] 회원정보 수정 화면 입력값 검증
- [ ] 프로필 이미지 업로드 및 미리보기 점검

### 검색 및 필터
- [ ] 검색어 입력 시 Debounce 동작 확인
- [ ] 검색 조건 변경 시 결과 갱신 확인
- [ ] 복합 필터 선택 및 초기화 동작 점검

### UI / UX
- [ ] 모바일 화면 반응형 레이아웃 점검
- [ ] 로딩 및 오류 상태 UI 개선
- [ ] 사용자 입력 및 버튼 동작 확인

### 코드 품질
- [ ] 불필요한 import 및 코드 정리
- [ ] 컴포넌트 구조 및 재사용성 검토
- [ ] API 호출 및 오류 처리 방식 점검

## 관리 방향

기존 프론트엔드 기능과 개선 항목을 문서화하였으며,
