
# Chef's Cuisine - Backend Maintenance

## 프로젝트 개요

Chef's Cuisine은 레시피 공유, 검색 및 사용자 간 소통을 지원하는 웹 서비스입니다.

본 문서는 Spring Boot 기반 백엔드의 주요 기능과 향후 점검 항목을 정리한 문서입니다.

## 기술 스택

- Java 17
- Spring Boot
- MyBatis
- MySQL
- AWS EC2 / S3

## 주요 기능

### 회원 관리
- 회원가입 및 로그인 / 로그아웃
- 세션 기반 인증
- 회원정보 조회 및 수정
- 프로필 이미지 관리
- 회원 탈퇴 처리

### 레시피 검색 및 정렬
- 레시피명 검색
- 회원 닉네임 검색
- 최신순, 조회수순, 인기순, 스크랩순 정렬
- 난이도, 조리시간, 태그, 재료별 복합 검색

### 스크랩 관리
- 레시피 스크랩 등록 및 해제
- 마이페이지 스크랩 목록 조회

## 향후 점검 및 개선 항목

### 회원 관리
- [ ] 세션 인증 및 접근 권한 처리 점검
- [ ] 회원정보 수정 시 입력값 검증 확인
- [ ] 회원 탈퇴 처리 로직 검토

### 검색 및 정렬
- [ ] MyBatis 동적 SQL 조건 처리 점검
- [ ] 복합 검색 조건의 AND 처리 확인
- [ ] 정렬 기준별 조회 결과 검증
- [ ] 검색 및 목록 조회 성능 검토

### 스크랩
- [ ] 스크랩 중복 등록 방지 로직 확인
- [ ] 스크랩 등록 및 해제 트랜잭션 점검

### 코드 품질
- [ ] 불필요한 코드 및 주석 정리
- [ ] 예외 처리 방식 개선
- [ ] API 응답 구조 일관성 검토
