# Chef's Cuisine

> 레시피 공유·검색을 통해 다양한 요리 정보를 탐색하고 사용자 간 소통할 수 있는 레시피 웹 서비스

---

## 담당 역할

- 회원 관리 기능 구현
- 복합 조건 검색 기능 구현
- 레시피 정렬 기능 구현
- 레시피·회원 통합 검색창 기능 구현
- 레시피 스크랩 기능 구현
- 공공 레시피 데이터 검수 및 이미지·태그 데이터 보완
- GitHub를 활용한 팀 협업 및 Merge Conflict 해결

---

## 담당 기능

### 1. 회원 관리

회원가입·로그인·로그아웃부터 회원정보 조회·수정 및 탈퇴까지 회원 관리 기능 구현

- 닉네임, 프로필 이미지, 소개글 등 회원정보 조회 및 수정
- 회원 탈퇴 시 회원 데이터를 삭제하지 않고 상태를 비활성화하는 방식으로 처리

---

### 2. 복합 조건 검색

사용자가 원하는 레시피를 쉽게 찾을 수 있도록 여러 조건을 조합한 검색 기능 구현

- 난이도, 조리시간, 태그, 재료 등 다중 검색 조건 지원
- 난이도 / 조리시간은 3가지 범위로 구분

---

### 3. 레시피 정렬

사용자가 원하는 기준으로 레시피를 탐색할 수 있도록 정렬 기능 구현

- 최신순, 인기순, 스크랩순, 조회순 정렬 지원
- 인기순은 `스크랩 수 + 추천 리뷰 수`를 기준으로 정렬

---

### 4. 통합 검색창

복합 조건 검색과 별도로 검색어만 입력해 레시피와 회원을 빠르게 찾을 수 있도록 통합 검색 기능을 제안하고 구현

- 하나의 검색창에서 레시피와 회원을 동시에 검색
- 동일한 검색어로 레시피 API와 회원 API를 각각 호출
- 검색 결과를 레시피 / 회원 영역으로 구분하여 출력

---

### 5-5. 레시피 스크랩

사용자가 관심 있는 레시피를 저장하고 다시 확인할 수 있도록 스크랩 기능을 구현

- 로그인한 사용자만 스크랩 기능을 사용할 수 있도록 처리
- 기존 스크랩 여부를 확인하여 하나의 요청에서 등록 / 해제 처리
- 마이페이지에서 스크랩한 레시피 목록 조회

> **참고:** 개발 초기 팀원 간 기능 명칭에 대한 소통 차이로 스크랩 관련 코드 일부에 `Like` 명칭이 사용되었습니다. 실제 서비스에서는 '스크랩' 기능으로 제공했습니다.

## 문제 해결 경험

### 1. 회원 탈퇴 시 작성 레시피가 사라지는 문제

**문제**

회원 탈퇴 시 작성한 레시피까지 함께 사라지는 문제가 있어, 탈퇴 회원의 레시피는 기존 콘텐츠로 유지하는 것이 적절하다고 판단

**원인**

회원 탈퇴 처리와 기존 작성 콘텐츠의 유지가 분리되지 않아 탈퇴한 회원의 레시피까지 함께 조회 불가

**해결**

회원 데이터를 삭제하는 대신 **회원 상태를 비활성화하는 방식으로 탈퇴 로직을 변경**  
탈퇴 회원의 정보 조회와 서비스 이용은 제한하면서 기존 작성 레시피 데이터는 유지되도록 처리

**결과**

탈퇴한 회원의 정보는 조회되지 않지만 해당 회원이 작성했던 레시피는 다른 사용자가 계속 조회할 수 있도록 개선

---

### 2. 조리시간 검색 범위 중복 문제

**문제**

조리시간 조건 검색 시 선택한 시간 범위와 다른 레시피가 함께 조회되는 문제가 발생

**원인**

조리시간 카테고리별 검색 범위가 명확하게 분리되지 않아 조건이 서로 겹치는 상태

**해결**

MyBatis 동적 SQL의 조건을 수정하여 조리시간 범위를 다음과 같이 분리

- 10분 이하
- 10분 초과 ~ 30분 이하
- 30분 초과

**결과**

조리시간 조건의 중복을 제거하여 사용자가 선택한 시간 범위에 해당하는 레시피만 조회되도록 개선

---

### 3. Git Merge Conflict 해결

**문제**

팀원 3명이 각각 기능을 개발한 뒤 코드를 병합하는 과정에서 동일한 파일의 수정 내용이 겹쳐 Merge Conflict가 발생

**원인**

각자 기능을 구현하는 과정에서 여러 팀원이 공통 파일을 수정하면서 브랜치 간 변경 내용이 충돌

**해결**

Git에서 충돌이 발생한 부분을 확인하고 각 브랜치의 변경 내용을 비교하여 필요한 코드를 직접 선택하고 통합

**결과**

각 팀원이 개발한 기능을 하나의 프로젝트로 정상적으로 병합했으며, 공통 파일 수정과 코드 병합 과정에서 팀원 간 사전 소통의 중요성을 경험
