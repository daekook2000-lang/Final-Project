# Chef's Cuisine

> 레시피 공유·검색을 통해 다양한 요리 정보를 탐색하고 사용자 간 소통할 수 있는 레시피 웹 서비스

---

## 담당 역할

- 회원 관리 기능 구현
- 복합 조건 검색 기능 구현
- 레시피 정렬 기능 구현
- 레시피·회원 통합 검색창 기능 구현
- 레시피 스크랩 기능 구현
- 공공 레시피 데이터 검수 및 이미지·태그 데이터 보완
- GitHub를 활용한 팀 협업 및 Merge Conflict 해결

---

## 프로젝트 개요

- **개발 기간** : 2026.05.27 ~ 2026.06.30
- **개발 인원** : 3명
- **개발 목적** : 다양한 조건으로 원하는 레시피를 검색하고, 사용자 간 레시피를 공유할 수 있는 웹 서비스 구현
- **담당 역할** : 회원 관리, 복합 조건 검색, 레시피 정렬, 통합 검색창, 레시피 스크랩 기능 구현
